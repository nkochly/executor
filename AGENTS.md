# Work on the v2 branch, not main

`main` holds the retired v1 code and takes no new work. All work on this fork
happens on `claude/project-thread-qw4ysu` (v2).

1. Fetch it with `git fetch origin claude/project-thread-qw4ysu` and branch
   from it, never from `main`.
2. Open pull requests against `claude/project-thread-qw4ysu`.
3. Follow that branch's `AGENTS.md`. The v1 rules that used to sit here no
   longer apply.
